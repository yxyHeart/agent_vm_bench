## Browser（完整页面版, 2026-09-16 凌晨）

### 页面集修复（方法学）

`download_page.sh` 在今日 Wikipedia 上失效的根因与修复:
- **缩略图域名迁移**: Wikipedia 已将 `src` 缩略图拆到 `thumb.wikimedia.org`, 脚本提取正则只认
  `upload.wikimedia.org` → 修复: HTML 下载后把 `//thumb.wikimedia.org/` 还原为
  `//upload.wikimedia.org/`（两域名同路径同内容）, 提取数 6 → 3149
- **BSD sed 静默失败**: macOS 上 GNU 语法 `sed -i 's|…|…|g'` 失败且不报错 → 修复: 加 perl 兜底
- **全尺寸原图字节配额**: `upload.wikimedia.org` 对大文件（srcset 2x 原图）限流 429, 缩略图不受影响;
  147 张原图中 91 张恢复期补下成功, 剩 56 张（全部 List_of_paintings 大图）按"正常失败"接受

最终页面集: **10 页 HTML 全部本地化（远端引用 0）, 3115 张图片 223MB**;
9/10 页面引用 100% 落盘（China 206/206, Hubble 156/156 …）, List_of_paintings 2248/2304。
